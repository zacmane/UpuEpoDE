# Geolocator study of Eurasian Hoopoes in Germany

## Description

This repository contains the raw data and the trajectory information generated with the GeoPressureR workflow. It contains data from 7 tag deployments on 6 individual Eurasian Hoopoes (Upupa epops) breeding in nest boxes in Marienfließ, northern Germany, between 2023 and 2026 (one bird was tracked over two consecutive annual cycles). Five deployments combine light and pressure data, while two are light-only tracks, as pressure data could not be reliably used for those individuals.

The GeoLocator Data Package (`data/tags.csv`, `data/observations.csv`) built from this repository is archived on Zenodo (DOI: https://doi.org/10.5281/zenodo.23211897).

This repository was generated based on [GeoPressureTemplate (v1.1)](https://github.com/Rafnuss/GeoPressureTemplate).
